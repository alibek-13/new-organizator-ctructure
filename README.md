# Организатор структуры - Управление подразделениями

Веб-приложение для управления организационной структурой с поддержкой иерархических подразделений и отслеживанием показателей.

## Что умеет приложение?

### Основные возможности:

1. **Управление подразделениями**
   - Добавление городов/отделений с указанием общего и фактического количества
   - Удаление подразделений
   - Создание многоуровневой иерархии подразделений

2. **Работа с подзаголовками**
   - Добавление подзаголовков (субподразделений) к любому подразделению
   - Удаление подзаголовков
   - Неограниченная вложенность структуры

3. **Отслеживание показателей**
   - Учёт общего количества единиц
   - Учёт фактического количества единиц
   - Автоматическое проставление даты создания записей

4. **Статистика**
   - Раздел для просмотра аналитических данных
   - Возможность интеграции с внешними API

### Технологический стек:

- **Frontend Framework:** Vue.js 2.6
- **Маршрутизация:** Vue Router 3.5
- **Управление состоянием:** Vuex 3.6
- **HTTP клиент:** Axios 1.1
- **Визуализация:** Chart.js 3.9
- **Генерация UUID:** vue-uuid 2.0
